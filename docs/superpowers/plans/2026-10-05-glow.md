# LUMEN GLOW Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task, unless the user selects subagent-driven-development. Steps use checkbox syntax for tracking.

**Goal:** Turn the viewer's entire visible body into a luminous silhouette with six selectable colors.

**Architecture:** A React shell owns one reusable webcam hook. A MediaPipe worker generates segmentation masks from captured frames, and an animation loop consumes those masks through refs. WebGL renders filled light and bloom, with a Canvas fallback.

**Tech Stack:** JavaScript, React, Vite, MediaPipe Tasks Vision, WebGL, Node test runner, Playwright.

**Spec:** `docs/phase-1-design.md`

## Global Constraints

- Implement foundation and GLOW only.
- Never render camera pixels.
- Locally serve the model and WASM assets.
- Preserve the input aspect ratio and mirror the mask consistently.
- Stop and unmount release every media track.
- No Three.js is needed in Phase 1.

## Review Focus

- Permission resolves after Stop: the late stream must be released.
- Tracking disappears: stale silhouettes must fade away.
- Worker inference fails: pending input must unblock and show retry guidance.
- Portrait viewport: the entire camera frame must fit without stretching.
- WebGL context unavailable or lost: Canvas fallback must keep color selection usable.
