## Committed local production preview

Use PowerShell in the existing checkout. Do not run a dev server, install packages, fetch assets, or change branches during acceptance. Dependencies and local runtime assets must already be present. If unavailable, stop and record the blocker. These commands build the committed source and serve it only on loopback; they do not deploy.

```powershell
Set-Location 'C:\Users\joecl\Downloads\Lumen'
$acceptanceBranch = git branch --show-current
if ($LASTEXITCODE -ne 0 -or $acceptanceBranch -ne 'feat/energy-rush') { throw 'Wrong acceptance branch' }
$acceptanceChanges = @(git status --porcelain)
if ($LASTEXITCODE -ne 0 -or $acceptanceChanges.Count -ne 0) { throw 'Commit or resolve working-tree changes before acceptance' }
$acceptanceHead = git rev-parse HEAD
if ($LASTEXITCODE -ne 0) { throw 'Cannot read committed HEAD' }
git log -1 --format='%H %s'
Write-Output "Acceptance source HEAD: $acceptanceHead"

# If node/npm are unavailable, prepend this checkout's bundled Node directory.
if (-not (Get-Command node -ErrorAction SilentlyContinue)) {
    $acceptanceNodeDir = "$PWD\.tools\node-v22.23.3-win-x64"
    if (-not (Test-Path -LiteralPath "$acceptanceNodeDir\node.exe")) { throw 'Locate bundled node.exe first' }
    $env:PATH = "$acceptanceNodeDir;$env:PATH"
}
$acceptanceNodeVersion = node --version
if ($LASTEXITCODE -ne 0) { throw 'Node unavailable; require >=22.12.0' }
Write-Output $acceptanceNodeVersion
$acceptanceNodeParts = $acceptanceNodeVersion.TrimStart('v').Split('.')
if ([int]$acceptanceNodeParts[0] -lt 22 -or ([int]$acceptanceNodeParts[0] -eq 22 -and [int]$acceptanceNodeParts[1] -lt 12)) { throw 'Require Node >=22.12.0' }
npm.cmd --version
if ($LASTEXITCODE -ne 0) { throw 'npm unavailable beside bundled Node' }
npm.cmd run build
if ($LASTEXITCODE -ne 0) { throw 'Production build failed' }
if ((git rev-parse HEAD) -ne $acceptanceHead -or @(git status --porcelain).Count -ne 0) { throw 'Source identity changed during build' }
npm.cmd run preview -- --port 4173 --strictPort
```
